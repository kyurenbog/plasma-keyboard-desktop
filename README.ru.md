# Plasma Keyboard Desktop

Русская инструкция · [English instructions](README.md)

Расширенная экранная клавиатура для **Fedora KDE Plasma под Wayland**. Добавляет служебные клавиши и сочетания в Plasma Keyboard 6.7.5, сохраняя переключение английского и русского языков.

Это пользовательский патч и набор раскладок, не официальный выпуск KDE. Исправленная программа устанавливается отдельно в домашнюю папку. Системный пакет Fedora остаётся установленным.

## Возможности

- Esc и F1–F12.
- Сочетания с Ctrl, Alt и Meta, в том числе со стрелками.
- Tab, Backspace, Enter, Delete, Home, End, Page Up и Page Down.
- Стрелки и привычное смещение буквенных рядов: Q → A → Z / Й → Ф → Я.
- Английская и русская раскладки с одинаковой шириной буквенных клавиш.
- Без отдельного цифрового ряда: цифры и символы доступны на символьном слое.
- Текстовая надпись **Backspace** вместо значка, который может отображаться квадратом.

## Совместимость

Проверено на **Fedora 44 KDE, aarch64, Plasma Keyboard 6.7.5, Qt Virtual Keyboard 6.11.2**.

Нужны сеанс Plasma **Wayland** и установленный системный пакет `plasma-keyboard`. Сборка требует Qt ≥ 6.10, KDE Frameworks ≥ 6.26 и Plasma ≥ 6.7. Программа собирается на самом устройстве; готового бинарника только для ARM в репозитории нет. Другие архитектуры и дистрибутивы не проверялись. Патч предназначен именно для **v6.7.5**.

## Установка

Открой Konsole в обычном графическом сеансе. Права sudo нужны только для установки зависимостей.

```bash
sudo dnf install -y git
git clone https://github.com/kyurenbog/plasma-keyboard-desktop.git
cd plasma-keyboard-desktop
bash scripts/install-deps.sh
bash scripts/build.sh
bash scripts/install.sh
bash scripts/activate.sh
```

`build.sh` скачивает исходники KDE v6.7.5, применяет патч из репозитория и собирает программу. Нужны интернет и пакеты для разработки. По умолчанию используются три потока; при нехватке памяти запусти `JOBS=2 bash scripts/build.sh`. В этой сборке отключены звуки клавиш и вибрация.

Коснись текстового поля, чтобы открыть клавиатуру. Её также можно выбрать в **Параметры системы → Клавиатура → Виртуальная клавиатура → Plasma Keyboard Extended**. Если пункт не появился сразу, переоткрой параметры или выйди из сеанса и войди снова.

Установщик копирует системные языковые раскладки и заменяет английскую fallback-раскладку и основной русский слой. Существующие пользовательские раскладки, файл запуска и исправленный бинарник сохраняются в резервную копию. Путь к ней выводится после установки.

## Как пользоваться сочетаниями

Модификаторы включаются **на одну следующую клавишу**, удерживать их не нужно:

1. Коснись **Ctrl** — кнопка подсветится.
2. Коснись **C** для Ctrl+C или **V** для Ctrl+V.
3. После этого Ctrl сбросится.

Для сочетания нескольких модификаторов нажми их по очереди, затем нужную клавишу. Повторное касание подсвеченного модификатора отменяет его. Shift использует штатное поведение Qt.

Meta — аналог Windows/Super. Действие зависит от настроек Plasma и приложения. На физические события влияет и системная раскладка; установщик не меняет настройки языков системы.

## Обновление

```bash
cd plasma-keyboard-desktop
git pull --ff-only
```

Если изменились только раскладки или скрипты установки, повтори `install.sh` и `activate.sh`. Если изменились C++-патч или протокол, сначала собери программу в **новой папке**, чтобы не использовать старые пропатченные исходники:

```bash
export PLASMA_DESKTOP_BUILD_DIR="$PWD/build/update-$(date +%Y%m%d-%H%M%S)"
bash scripts/build.sh
bash scripts/install.sh
bash scripts/activate.sh
```

После крупных обновлений Qt/Plasma может понадобиться пересборка или адаптация патча. Отдельная копия программы не получает исправления Fedora для Plasma Keyboard автоматически.

## Возврат штатной клавиатуры

```bash
bash scripts/restore-stock.sh
```

Скрипт выбирает штатную клавиатуру Fedora и переименовывает папку пользовательских раскладок в `layouts.disabled-<время>`, чтобы загружались системные. Исправленный бинарник и резервные копии сохраняются. Переименование касается всей папки пользовательских раскладок, включая добавленные тобой отдельно.

Для возврата конкретного предыдущего варианта используй папку резервной копии, указанную установщиком. В ней находятся прежние раскладки и, если они были, бинарник и файл запуска. Перед заменой работающей исправленной клавиатуры переключись на штатную.

## Куда устанавливаются файлы

| Назначение | Путь по умолчанию |
| --- | --- |
| Исправленный бинарник | `~/.local/opt/plasma-keyboard-desktop/bin/plasma-keyboard` |
| Файл запуска | `~/.local/share/applications/org.kde.plasma.keyboard.desktop-extended.desktop` |
| Раскладки | `~/.local/share/plasma/keyboard/layouts/` |
| Резервные копии установки | `~/.local/share/plasma/keyboard/desktop-backups/` |
| Исходники и результаты сборки | `./build/` |

Пути данных учитывают `XDG_DATA_HOME`. Переменная `PLASMA_DESKTOP_BUILD_DIR` задаёт другую папку сборки — используй одинаковое значение для сборки и установки. `PLASMA_DESKTOP_PREFIX` позволяет изменить папку установки бинарника. Запускай скрипты от обычного пользователя, не через `sudo bash scripts/install.sh`.

## Если что-то не работает

**Клавиатура не открывается:** запусти `activate.sh` из Konsole внутри сеанса Plasma и коснись текстового поля. Проверь Wayland командой `echo "$XDG_SESSION_TYPE"`. Программу должен запускать KWin как выбранную виртуальную клавиатуру; напрямую запускать бинарник не нужно.

**Вместо Ctrl+C печатается буква:** проверь, что выбрана **Plasma Keyboard Extended**. Одни раскладки не исправляют сочетания в штатном бинарнике 6.7.5. Перезапусти через `activate.sh`.

**Ошибка сборки:** посмотри первую реальную ошибку CMake или компилятора, установи зависимости и проверь версии. Для старых Fedora или несовместимых новых версий upstream может понадобиться другой патч.

**Пропали пользовательские языковые изменения:** системные языки копируются, а прежние пользовательские изменения сохраняются в резервную копию без автоматического объединения. Верни нужные файлы из неё.

Последние сообщения для диагностики:

```bash
journalctl --user --since "5 minutes ago" --no-pager | grep plasma-keyboard
```

## Устройство и проверка

В Plasma Keyboard 6.7.5 буквенные события превращаются в текст, а путь keysym передаёт нулевые модификаторы. Патч направляет сочетания и поддерживаемые служебные клавиши через **KWin fake-input**, используя Linux-коды клавиш. Очередь отпускает модификаторы до следующего сочетания. Обычный текст продолжает идти через метод ввода.

На планшете отдельное Qt-приложение получило Ctrl+A, Ctrl+C, Ctrl+Left, Shift+Left и Alt+X с правильными модификаторами, а F5 — без оставшихся модификаторов. См. [результаты проверки](docs/verification.txt). Автоматический тестовый ввод удалён из рабочей программы. Обработка касаний и конкретных сочетаний также зависит от целевого приложения.
