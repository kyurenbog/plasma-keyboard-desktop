# Создание раскладки для своего языка

[English](custom-layouts.md) · [Установка проекта](../README.ru.md)

Начни с уже установленной Plasma Keyboard Extended. Для изменения букв и геометрии достаточно QML-файлов; пересобирать C++ нужно только при изменении обработки событий или таблицы сочетаний.

## 1. Найди папку и код языка

Ниже команды для **Bash**: если используешь Fish, сначала выполни `bash`. Работай от обычного пользователя, без sudo. Запускай команды из папки репозитория.

```bash
layouts="${XDG_DATA_HOME:-$HOME/.local/share}/plasma/keyboard/layouts"
ls "$layouts"
```

Папки называются по локали Qt, например `es_ES`, `de_DE`, `fr_FR`, `uk_UA`. Выбирай реальную локаль, поддерживаемую Qt, а не произвольное имя вроде `my_keyboard`. Папка `fallback` общая: её изменение затронет все языки, которые на неё ссылаются.

Файлы `main.qml` задают основной слой, `symbols.qml` — символьный. Файлы `.fallback` означают использование общего слоя. Копирование основного слоя не переводит символы или другие слои автоматически.

## 2. Подготовь основу с резервной копией

Пример ниже создаёт основу для **испанского `es_ES`**, сохраняя F-клавиши и модификаторы. Это заготовка, не полная испанская раскладка.

```bash
target_locale=es_ES
backup="${XDG_DATA_HOME:-$HOME/.local/share}/plasma/keyboard/custom-backups/$(date +%Y%m%d-%H%M%S)-$$"
mkdir -p "$backup" "$layouts/$target_locale"
cp -a "$layouts/$target_locale" "$backup/"
cp "$layouts/fallback/main.qml" "$layouts/$target_locale/main.qml"
if [ -f "$layouts/$target_locale/main.fallback" ]; then
  mv "$layouts/$target_locale/main.fallback" "$backup/main.fallback"
fi
kate "$layouts/$target_locale/main.qml"
```

Используй любой текстовый редактор вместо Kate. Сохраняй файл в **UTF-8**. Не меняй системные файлы в `/usr/share`.

Для языка с уже существующей сложной раскладкой сначала изучи её исходный `main.qml`. Замена на английскую заготовку может убрать необходимую этому языку обработку ввода.

## 3. Измени буквы и их порядок

Одна кнопка выглядит так:

```qml
PcKey { text: "a"; key: 65; weight: 100 }
```

`text` — надпись и вводимый текст. `key` — код клавиши Qt, а не Linux-код. `weight` — относительная ширина. Порядок кнопок внутри `KeyboardRow` определяет их расположение.

Например, испанская Ñ занимает позицию клавиши `;` на US-клавиатуре. Можно заменить кнопку `;` на:

```qml
PcKey { text: "ñ"; key: Qt.Key_Semicolon; weight: 100 }
```

Обычное касание вводит текст `ñ`, а сочетание использует поддерживаемую физическую позицию `KEY_SEMICOLON`. Для ожидаемого поведения сочетаний системная раскладка тоже должна соответствовать испанской. Выбор языка экранной клавиатуры сам по себе её не переключает.

Если меняешь порядок букв, учитывай одновременно надпись, физическую позицию и системную раскладку. Механическая замена только надписи не гарантирует ожидаемых сочетаний.

Сохрани определения `PcKey`, `ModifierKey`, `latchedModifiers` и обработчик `onClicked`: они обеспечивают однократные Ctrl/Alt/Meta. Также оставь `ChangeLanguageKey`, чтобы переключать языки.

## 4. Сохрани смещения рядов

Обычная буква имеет `weight: 100`. В текущей геометрии каждый буквенный ряд суммарно равен **1500**:

| Ряд | Левый отступ | Остальные кнопки |
| --- | --- | --- |
| Верхний | Tab: 150 | буквы/символы и Backspace |
| Средний | FillerKey: 175 | буквы/символы и Enter |
| Нижний | Shift: 225 | буквы/символы, отступ и стрелка вверх |

```qml
FillerKey { weight: 175 }
```

Это пустой промежуток. Если добавил букву шириной 100, уменьши свободное место или ширину служебных клавиш на 100 в том же ряду. При одинаковой сумме ширин буквы остаются одинаковыми по размеру. Отступы 150 → 175 → 225 дают привычное смещение Q → A → Z. Для языка с другой формой клавиатуры выбери свои отступы, сохранив равную общую ширину рядов.

## 5. Подключи и проверь язык

```bash
bash scripts/activate.sh
```

В настройках экранной клавиатуры включи нужный язык и выбери его кнопкой переключения языка. Если языка нет, проверь код папки, `main.qml` и перезапусти клавиатуру. Настройки обычной аппаратной клавиатуры и список языков экранной — отдельные настройки.

Проверь обычные буквы, Shift, пробел, Backspace, Enter, символьный слой, Ctrl+C/V и Ctrl+стрелки в редакторе. Затем проверь переключение обратно на английский/русский. Для ошибок QML:

```bash
journalctl --user --since "5 minutes ago" --no-pager | grep plasma-keyboard
```

## 6. Если сочетание с новой буквой не работает

Патч поддерживает определённые Qt-коды: латинские буквы, русские буквы, цифры и перечисленные служебные клавиши. Новый Unicode-код, например `0x00D1`, сам по себе **не добавляется** в таблицу физических клавиш. Обычная печать может работать, а сочетание — нет.

Есть два варианта: использовать подходящий уже поддерживаемый Qt-код физической позиции, как в примере Ñ, или расширить `desktopScanCode()` в C++-патче. Linux-коды берутся из `linux/input-event-codes.h`; их нельзя подставлять напрямую в QML-свойство `key`.

Для изменения C++ работай с исходниками v6.7.5, обнови `patches/desktop-shortcuts.patch` относительно чистой версии и собери в новой `PLASMA_DESKTOP_BUILD_DIR` по инструкции обновления. Простое редактирование уже пропатченной папки `build/` не переносит изменение в распространяемый патч.

Китайский/японский ввод, композиция, dead keys и нестандартные правила регистра требуют большего, чем замена букв. `PcKey` отправляет прямой текст и использует обычный `toUpperCase()`; языковые движки, словари и правила композиции автоматически не добавляются. Для таких языков сохраняй штатный метод ввода и адаптируй раскладку отдельно.

## 7. Сохрани работу перед переустановкой

Установщик заново копирует системные раскладки и генерирует английскую/русскую. Пользовательские изменения сохраняются в резервную копию, но **не подхватываются автоматически**. Сохрани свою папку отдельно, например вне репозитория:

```bash
saved_layouts="$HOME/Documents/plasma-keyboard-custom-layouts"
mkdir -p "$saved_layouts"
cp -a "$layouts/$target_locale" "$saved_layouts/"
```

После обновления и `install.sh`, до `activate.sh`, верни её:

```bash
cp -a "$saved_layouts/$target_locale/." "$layouts/$target_locale/"
if [ -f "$layouts/$target_locale/main.fallback" ]; then
  mv "$layouts/$target_locale/main.fallback" "$backup/restored-main.fallback"
fi
bash scripts/activate.sh
```

Команды восстановления предполагают, что переменные из предыдущих шагов заданы; в новом терминале задай их снова. Английскую/русскую раскладку для постоянного распространения меняй в `scripts/generate_layouts.py`: ручные изменения сгенерированных файлов заменятся при установке. Добавление ещё одного элемента в список языков генератора требует также адаптации его условий для символов и ширины рядов — сейчас они рассчитаны на английский и русский.

## Пример: украинский язык

В **Клавиатура → Виртуальная клавиатура (Virtual Keyboard)** выбирается **Plasma Keyboard Extended**. В соседнем разделе **Клавиатура → Экранная клавиатура (On-Screen Keyboard)** отмечаются языки. Выбор украинского там включает существующую раскладку `uk_UA`, но не преобразует её в расширенную.

Для украинского удобно взять расширенный `ru_RU/main.qml` за основу вместо английского `fallback/main.qml`. Сначала сохрани резервную копию папки `uk_UA` по шагу 2. Затем помести адаптированный основной слой в:

```text
~/.local/share/plasma/keyboard/layouts/uk_UA/main.qml
```

Если задан `XDG_DATA_HOME`, используй его вместо `~/.local/share`. Сохрани украинские символьные слои и методы ввода, если они нужны. Замени русские буквы на украинские, проверь наличие **і, ї, є, ґ** и их верхнего регистра; при добавлении клавиш пересчитай ширины рядов. Сохрани служебные кнопки и обработчики модификаторов.

После перезапуска включи украинский в **On-Screen Keyboard**, нажми **Применить** и переключись на него кнопкой языка. Вид и служебные клавиши будут задаваться новым украинским `main.qml`, как у английского и русского. Отдельно проверь сочетания: используй подходящие поддерживаемые коды физических позиций или расширь C++-таблицу по шагу 6. Простая замена подписей не гарантирует работу всех сочетаний с новыми буквами.

Это инструкция по адаптации: готовая расширенная украинская раскладка в пакет пока не включена. Сохраняй её отдельно перед переустановкой по шагу 7.
